# 📊 Sales Data Analysis - IHUB Project

### Overview
Analyzed 9,900+ retail sales records to find revenue trends, profit and top products.

### 🔑 Key Insights
- Top 5 products generate 65% revenue
- West region is highest selling region
- Monthly sales trend analysis done

### 🛠️ Tech Stack
Python, Pandas, Matplotlib, Excel

### 📁 Files
- `sales.csv.csv` - Main dataset (9900 rows)
- `analysis.ipynb` - Analysis notebook

### ▶️ How to Run
pip install pandas matplotlib
Open notebook and run
