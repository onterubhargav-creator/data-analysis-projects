# 📊 Sales Data Analysis - IHUB Project

### Overview
Analyzed 9,900+ retail sales records using Python and Tableau to find revenue trends and business insights.

### 🔑 Key Insights (Tableau Dashboard)
- Top 5 products generate 65% of total revenue
- West region is the highest selling region
- Monthly sales trend - Q4 has peak sales
- Profit margin analysis by category

### 🛠️ Tech Stack
Python (Pandas), Tableau, Excel
